# Roy Chemo

Full-stack developer in Tel Aviv. Founder of [Kashuv](https://kashuv.ai), AI voice and WhatsApp agents for businesses. I build tools that make AI coding agents easier to run day to day, and I ship a new one to the stores every week or two. Claude Code writes the code; I define what it must do and test it on real work.

## Tools

**[Billable](https://github.com/roych28/billable)**: run every project on the right Claude account, and always know which one you are on. Account, cost and limits in the status bar, a cost report per account and month, switching in one click.
[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=roychemo.billable) · [Open VSX](https://open-vsx.org/extension/roychemo/billable) (Cursor, Windsurf) · [JetBrains](https://plugins.jetbrains.com/plugin/35266-billable)

**[ShipSight](https://github.com/roych28/shipsight)**: the eyes-on check of a live site after a deploy. Opens the live URL in Chrome and Safari's engine at desktop and phone widths, and reports buttons out of their box, cut text, sideways scroll, broken images and JS errors, with a screenshot for each.
[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=roychemo.shipsight) · Claude Code plugin: `/plugin marketplace add roych28/shipsight`

**[deploysmoke](https://github.com/roych28/deploysmoke)**: skills for Claude Code that stop your agent from breaking production: post-deploy smoke, prove it's live, safe git across parallel sessions, secret guard, permission unblock.
`/plugin marketplace add roych28/deploysmoke`
